1. ЧТО СКОПИРОВАТЬ НА ДРУГОЙ ПК
────────────────────────────────
Скопируйте всю папку целиком. В ней должны быть файлы:

  • ProgressBarsOpen.lnk        — запуск программы с фирменной иконкой
  • 1.Запуск_с_обновлением.cmd — служебный файл запуска и обновления
  • server.py                 — сервер сохранения (не трогать)
  • road-progress.html        — сама программа
  • road-progress-data.json   — ваши данные (слои и участки)
  • export_word.py            — модуль Word-отчёта (не трогать)
  • ИНСТРУКЦИЯ.txt             — эта инструкция

Важно: файл road-progress-data.json — это ваши актуальные данные.
Если его не скопировать, на новом ПК будут исходные значения из таблицы.


2. ЧТО НУЖНО УСТАНОВИТЬ
────────────────────────
Нужен только Python 3. Других программ и библиотек ставить не нужно —
всё остальное уже внутри папки.

Python — бесплатная программа, ~25 МБ.


3. УСТАНОВКА PYTHON (один раз)
───────────────────────────────
1) Откройте сайт: https://www.python.org/downloads/
2) Нажмите жёлтую кнопку «Download Python 3.x.x»
3) Запустите скачанный установщик
4) Внизу окна ОБЯЗАТЕЛЬНО поставьте галочку:
     ☑ Add python.exe to PATH
   (без этой галочки программа не запустится!)
5) Нажмите «Install Now» и дождитесь окончания
6) Закройте установщик


4. КАК ЗАПУСКАТЬ ПРОГРАMMУ
──────────────────────────
1) Откройте папку с программой
2) Дважды щёлкните по ярлыку ProgressBarsOpen.lnk
3) Откроется чёрное окно и браузер с программой
4) Редактируйте слои и участки как обычно
5) Внизу страницы должно появиться:
     «сохранено → road-progress-data.json»

Не закрывайте чёрное окно, пока работаете — через него идёт сохранение.
Когда закончили — просто закройте окно запуска.

Программа сама проверяет обновления каждые 30 минут. Если новая версия найдена,
в правом верхнем углу появится уведомление. Нажмите «Обновить», чтобы установить
её и автоматически перезапустить программу, или «Свернуть», чтобы вернуться к ней позже.


5. КАК СОХРАНЯЮТСЯ ДАННЫЕ
──────────────────────────
Все изменения автоматически записываются в файл:
  road-progress-data.json

Он лежит в той же папке. Можно:
  • скопировать папку на флешку или другой ПК
  • отправить файл road-progress-data.json коллеге
  • сделать резервную копию (просто скопировать файл)


6. НОВЫЕ ВОЗМОЖНОСТИ
────────────────────────────────
• Объекты: создавайте несколько объектов и переключайтесь между ними в верхней панели.
• План и факт: откройте слой и укажите «План на дату»; сводка покажет отклонение.
• Контроль качества: при добавлении участка укажите ответственного и качество/акт.
• Фильтр и поиск ПК: показывайте незавершённые/отстающие слои и находите нужный ПК.
• Журнал: последние действия по объекту отображаются в нижней части страницы.

7. EXCEL, РЕЗЕРВНЫЕ КОПИИ И ОТЧЁТЫ
────────────────────
Внизу программы доступны кнопки:

  • «Скачать отчёт PDF» — белый лист с диаграммами для печати
  • «Скачать отчёт Word» — развёрнутый отчёт .docx с планом, участками и качеством
  • «Скачать Excel» — сводка и лист «Участки» для обмена данными
  • «Импорт Excel» — загружает лист «Участки» с колонками «Слой», «От, ПК», «До, ПК»
  • «Резервная копия» и «Восстановить» — ручное создание и возврат копии

PDF формируется в браузере (нужен интернет при первом открытии страницы).
Word формируется через сервер — нужен запущенный файл запуска.
Копии автоматически создаются перед сохранением в папке backups.


8. ЕСЛИ НЕ РАБОТАЕТ
────────────────────
«'...' is not recognized...» или другая ошибка в чёрном окне
  → Запустите 1.Запуск_с_обновлением.cmd ещё раз.
  → Или переименуйте папку без апострофа (например ProgressBars).

Python ne nayden / Python не найден
  → Python не установлен или не добавлен в PATH.
  → Переустановите Python с галочкой «Add python.exe to PATH».
  → Перезагрузите компьютер после установки.

Браузер не открылся
  → Откройте вручную: http://127.0.0.1:8765/road-progress.html

Изменения не сохраняются
  → Запускайте только через 1.Запуск_с_обновлением.cmd, не через road-progress.html.
  → Не закрывайте чёрное окно сервера во время работы.

Порт занят / ошибка при запуске
  → Закройте старое окно запуска и попробуйте снова.
  → Если не помогло — перезагрузите компьютер.


9. КРАТКО
─────────
  Установить:  Python 3 (с галочкой Add to PATH)
  Запуск:      двойной клик ProgressBarsOpen.lnk
  Данные:      road-progress-data.json (рядом с программой)
  Перенос:     копировать всю папку целиком
